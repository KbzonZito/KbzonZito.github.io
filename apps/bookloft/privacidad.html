Política de privacidad de Bookloft

Última actualización: 4 de noviembre de 2026

Esta política explica qué información trata Bookloft, desarrollada por KbzonZito.

Datos que recopila

Ninguno. Bookloft no tiene cuentas ni servidor propio. Tu biblioteca, notas y archivos se guardan solo en tu dispositivo.

Conexiones

La app solo se conecta a Open Library y Apple Books, para buscar libros y portadas; a Anthropic, solo si conectas tu propia API key; y a donde tú compartas un respaldo (Drive, correo, archivos).

Tu API key

Si usas las funciones de IA, tu API key de Anthropic se guarda cifrada en el Keystore del teléfono y nunca se incluye en los respaldos. Las imágenes que envíes a Claude se rigen por la política de privacidad de Anthropic.

Cámara y fotos

Solo se usan cuando escaneas un ISBN o eliges una foto, y la imagen no sale del teléfono salvo que uses la IA con tu API key.

Menores

La app no recopila información de ninguna persona, incluidos los menores de 13 años.

Cambios

Cualquier cambio se publicará en esta página con su fecha de actualización.

Contacto

Si tienes dudas sobre esta política, escribe a mvergaraguerrero@proton.me.
